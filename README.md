# Vintage Wheels — Car Rental Website

A responsive frontend college project inspired by the supplied Vintage Wheels reference image.

## Files
- `index.html` — page structure and content
- `style.css` — responsive vintage-inspired styling and a 9-car fleet
- `script.js` — mobile navigation, 9-car fleet filters (including Dodge Challenger and BMW Heritage), favourites, cost estimate and demo booking confirmation

## Run it
1. Extract the ZIP folder.
2. Open `index.html` in your browser, or open the folder in Visual Studio Code and use the Live Server extension.
3. Internet access is needed for the remote car photos and Google Fonts.

## Notes
- This is a frontend demo. The booking form does not submit to a server or store bookings.
- Car names, prices, and photos are sample content. Replace them with your own.
- To accept real reservations, connect the form to a backend/API and add validation, availability management, and secure data storage.
